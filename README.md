# আহমদিয়ান পরিবার-93

বাংলা cooperative-management website prototype for **আঁরা বিয়াক্কুন এক পরিবার**.

The current checkpoint contains the responsive public homepage, protected `/hisab` demo flow, Bengali accounting surfaces, and an explicitly marked demo Admin panel. Production Supabase Auth, server-side RBAC/RLS, CMS persistence, and Brevo notifications remain separate integration work and must be enabled without destructive data changes.
